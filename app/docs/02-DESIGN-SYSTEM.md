# Design System

## Visual Direction

Premium dark editorial technology.

Use:

- deep dark background
- off-white typography
- subtle gray surfaces
- thin borders
- one controlled accent
- strong typography

Avoid excessive color.

---

# Typography

Typography is a primary visual element.

Use:

Display font:
Large expressive headings.

Body font:
Highly readable sans-serif.

Monospace:
Technical metadata only.

---

# Typography Scale

Hero:
clamp(3.5rem, 9vw, 10rem)

Section:
clamp(2.5rem, 6vw, 7rem)

Project:
clamp(2rem, 4vw, 5rem)

Body:
16px–20px

Metadata:
12px–14px

---

# Layout

Use a consistent grid.

Desktop:
12 columns

Tablet:
8 columns

Mobile:
4 columns

Large whitespace is intentional.

---

# Borders

Use subtle borders for:

- cards
- navigation
- sections
- metadata

Avoid heavy containers.

---

# Buttons

Primary:

Minimal
Strong typography
Clear hover state

Secondary:

Text / arrow interaction.

Avoid excessive rounded pill UI.
