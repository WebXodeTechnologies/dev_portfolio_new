# Scroll Experience

## Scroll Philosophy

Scrolling should feel like navigating through a visual story.

Do not animate every element.

Create intentional chapters.

---

# Chapter 01 — Hero

Initial state:

Large typography.

WebGL scene behind content.

Scroll:

- typography moves
- WebGL camera changes
- scene depth increases
- hero exits

---

# Chapter 02 — Introduction

Large statement enters.

Example:

"I build digital products from interface to infrastructure."

Scroll:

Words reveal sequentially.

Background changes subtly.

---

# Chapter 03 — Selected Works

Project cards enter sequentially.

Featured project:

Large immersive presentation.

Scroll controls:

- image scale
- typography position
- metadata reveal
- WebGL distortion

---

# Chapter 07 — Hire

---

# Scroll Rules

Never trap the user unnecessarily.

Pinned sections must have clear progress.

Scroll animations must work with keyboard navigation.

Mobile should use simplified timelines.
