# Responsive Strategy

## Desktop

1920px
1440px
1280px

Full cinematic experience.

---

## Tablet

1024px
768px

Reduce:

- WebGL complexity
- animation distance
- particle count

---

## Mobile

390px
375px
360px

Priorities:

1. readability
2. navigation
3. performance
4. touch interaction
5. simplified animation

Never simply scale desktop down.

---

# Mobile WebGL

Use:

- fewer particles
- simpler shaders
- lower DPR
- fewer objects

If necessary, replace WebGL with static/animated visual.

---

# Touch

Never depend on:

hover

Provide touch-friendly alternatives.
